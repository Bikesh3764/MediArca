# Bug hunt and fix check — 27 Oct 2026

How this was done:
- Every backend controller and the main patient and desk screens were read by hand. The test suites were not used.
- Each suspected bug was then run against a local copy (production mode, local database on port 55433, server on 5077).
- The live site got read-only SQL checks only. Nothing live was changed.

**Result:**
- 25 bugs found. 22 were reproduced on the local copy; the other 3 were confirmed by reading the code.
- 49 fixes checked: 41 are fully in place, 6 are only partly in place, and 2 no longer apply.

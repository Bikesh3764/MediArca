# Taste Framework (`taste-framework`)

Taste is not arbitrary opinion; it is **trained restraint and deliberate judgment**. This framework prevents AI from behaving like a generic template generator and instead directs it to build bespoke, dignified, and calm software.

---

## 1. The Core Law: Subtraction Before Addition

When building or improving any screen:
1. **Remove 30% of what feels tempting to add**: Remove decorative icons that don't add meaning, remove redundant subtitle paragraphs, remove decorative gradient borders.
2. **Clarify the Core Verb**: What is the single thing the user came to this view to do? Highlight that verb with quiet confidence.
3. **Calm Clinical Confidence**: In healthcare, banking, and professional tools, calmness inspires trust. Avoid loud marketing claims, exclamation marks, or noisy animations.

---

## 2. Density Calibration

Interfaces must match the cognitive mode of the user:
- **Discovery Mode (Patients looking for doctors/clinics)**:
  - Generous whitespace, large touch targets, airy layout, clear photography/avatar, concise credentials.
- **Operations Mode (Doctors & Receptionists managing queues)**:
  - High information density, tabular clarity, instant keyboard shortcuts, fast status transitions, zero wasted scrolling.

---

## 3. Copywriting & Tone of Voice

| Bad / Slop Copy | Good / High-Taste Copy |
| :--- | :--- |
| "Experience our revolutionary next-gen healthcare queue platform today!" | "Walk-in & scheduled doctor queues with live status." |
| "Click here to initiate consultation encounter" | "Start Consultation" |
| "Doctor has currently stepped outside the clinical boundary" | "Doctor Stepped Out" |
| "Discover 100+ premier verified medical facilities near you" | "Explore Clinics" |

---

## 4. The "Apple Feel" Benchmark
To achieve true Apple Human Interface quality:
- **Card Edge Radius**: `20px` to `24px` with smooth squircle curvature.
- **Subtle Glassmorphism**: `backdrop-blur-xl bg-white/80 border-b border-black/5` on floating headers.
- **High-Contrast Dark Ink**: `#1d1d1f` for text on `#ffffff` surfaces.
- **Minimal Color Palette**: Pure white, soft canvas `#f5f5f7`, hairline borders `#e5e5ea`, and refined Apple Blue (`#0066cc`).
